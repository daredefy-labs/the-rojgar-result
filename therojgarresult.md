# The Rojgar Result Project Guide

The Rojgar Result website is a static government job and exam information portal.

## Main Pages

The site includes root HTML pages for:

- Home
- Latest Jobs
- Latest Results
- Admit Cards
- Answer Keys
- Syllabus
- Admission Forms
- Sarkari Yojana
- Upcoming Jobs
- About Us
- Contact Us
- Privacy Policy
- Terms and Conditions
- Disclaimer

## Theme

The website uses a common site theme with blue/red style colors, layout cards, navigation, and footer sections.

## Template Rules

- Keep the same header, footer, and navigation across pages.
- Keep metadata title, description, description keywords, canonical URL, Open Graph fields, and JSON-LD structure consistent.
- Prefer using the root page family and reusable layout patterns instead of creating extra demo HTML files.
- Use the `demo/` folder only as a reference area when the user wants to inspect layout examples.
