# The Rojgar Result

This is a static HTML website for government job updates, result announcements, admit cards, answer keys, syllabus pages, admission forms, and Sarkari Yojana information.

## Project Structure

- `index.html` — homepage
- `latest-jobs.html` — latest jobs page
- `latest-result.html` — latest result page
- `admit-card.html` — admit card page
- `answer-key.html` — answer key page
- `syllabus.html` — syllabus page
- `admission-form.html` — admission form page
- `sarkari-yojana.html` — Sarkari Yojana page
- `upcoming-jobs.html` — upcoming jobs page
- `about-us.html` — about page
- `contact-us.html` — contact page
- `privacy-policy.html` — privacy policy page
- `terms-and-conditions.html` — terms page
- `disclaimer.html` — disclaimer page
- `demo/` — demo/reference pages

## Styling

The site uses a shared CSS theme in `style.css` and shared JavaScript in `main.js`.

## Use

This project is static HTML and CSS. Open the HTML files in a browser directly or serve the folder locally using a static web server.
